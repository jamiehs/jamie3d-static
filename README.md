# jamie3d-static

Personal portfolio / business-card site. Vite + vanilla JS, hand-rolled CSS, deployed to Netlify.

## Develop

```
npm install
npm run dev
```

## Build

```
npm run build
npm run preview
```

Dashed `.todo` chips mark unfinished content. They're dev/preview-only — hidden in production builds via `import.meta.env.PROD` (see `src/main.js`).
